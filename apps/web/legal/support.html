Questions fréquentes

Mes données sont-elles envoyées sur un serveur ?

Non par défaut : elles restent dans votre navigateur. Elles ne sont copiées dans le cloud que si vous créez un compte Pro et activez la synchronisation.

Comment exporter ou supprimer mes données ?

Compte → Données : export JSON, effacement de l'appareil, suppression définitive du compte cloud.

Pourquoi un connecteur est-il « non configuré » ?

Certains fournisseurs exigent une application approuvée (Google, Microsoft, LinkedIn, X, TikTok, Meta). Σ l'indique honnêtement au lieu de simuler une connexion.

Comment résilier Pro ?

Compte → Abonnement → Gérer l'abonnement ouvre le portail client du prestataire de paiement.

Signaler une vulnérabilité

Écrivez à l'adresse ci-dessus avec « SECURITY » dans l'objet, sans données personnelles. Accusé de réception sous 72 heures.
